# 题库说明

`quiz-v2.json` 是 Web 与微信小程序唯一的权威题库。`challenges.json`、`costs.json` 与 `sources.json` 是 v1 历史稿和核查资料，不再驱动运行时。

- 所有项目统一以人民币汇总，界面金额统一保留 1 位小数；GPT `200 美元/月` 按 2026-07-16 官方中间价 `1 美元 = ¥6.7909` 折算为约 `¥1,358.2/月`、`¥16,298.2/年`，实际支付以账单汇率为准。六类金额分别记入已支付沉没成本、首年固定成本、次年续费、变动成本、待报价和注册资本门槛。
- 注册资本门槛、第三方询价和等保预算不会混入“已经花了”的现金。
- 题干和选项保持用户冻结原文；事实纠偏、官方时间与法律提醒只进入 `factNotes`。
- 评分是娱乐化产品测评值，不是合规评级；更贵、更大不会因此获得更高分。
- 题目只提醒玩家核对适用边界，不替代法律、财税或安全专业意见。
- 修改题库后运行 `npm run sync:mini`，为小程序生成可加载的静态模块。
