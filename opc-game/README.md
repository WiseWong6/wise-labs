# 一人公司生存模拟器

一个一屏一题的 25 题一人公司生存问卷。玩家可以继续承担成本，也可以随时退出并结算已经发生的费用、时间和待办。

Web 版为沉浸街机风格：复用像素版场景素材全屏铺开，手游 HUD、玻璃拟态选项卡与街机式确认反馈叠加其上，根路径 `/` 即游戏入口。项目同时提供原生微信小程序，Web 与小程序共用一份题库和同一套状态机。

像素版视觉源文件在 `design/characters/founder/` 与 `design/storyboards/`：包含人物母版、25 题场景 brief，以及记录 50 张双端母板尺寸、大小与 SHA-256 的 v2 清单。25 题条件路由与结算数据流见 `design/quiz-flow-v2.md`，账本、关键路径、分值和称号见 `design/settlement-v2.md`；相对最初原稿新增或替换的 9 题另列在 `design/quiz-new-questions-v2.md`，方便单独改文案。旧版 13 张分镜只作为画风参考，不参与新版完成度或运行时路由。运行时只读取仓库内的 WebP，不依赖远程图片。

配乐和 6 个交互音效由 `scripts/generate-audio-assets.mjs` 从零合成，不使用第三方采样或生成模型权重；Web 与小程序都在玩家点击“开始”后播放，并提供当前会话内的静音按钮。音频来源、取舍与哈希清单见 `design/audio-plan.md` 和 `design/audio-asset-manifest.json`。

## 零数据承诺

- 不提供登录、账号、排行榜、分享、历史记录或结果海报。
- Web 不使用 Cookie、Local/Session Storage、IndexedDB、网络请求、统计或错误上报。
- 小程序不调用登录、用户资料、网络请求、上传下载或 Storage API，并隐藏分享菜单。
- 答案和结果只存在当前运行内存中；刷新、关闭或重新进入即清空。
- 托管商或微信平台可能保留普通访问日志，但业务不会提交答案、账单或结局。

## 小红书小工具

小红书"小工具"是运行在受限沙箱里的离线 H5：不允许网络请求，所有资源必须打包在包内，ZIP 包体上限 10MB。本项目街机版与其"零数据"口径天然兼容，运行以下命令生成离线包：

```bash
npm run build:xhs
```

产物在 `output/xhs-tool.zip`，同时保留可检查的 `output/xhs-tool/` 目录：相对路径单入口 `index.html` + 外置 JS/CSS + 压缩后的全部场景图；音频以 base64 data URI 内联进 JS（包内不允许 mp3 等独立文件类型）。构建前需安装 `cwebp`（macOS：`brew install webp`）。打包脚本会自动裁剪未引用素材、压缩临时包内 WebP，并校验文件类型、外链、禁用 API、ZIP 根目录和 10MB 上限。上传入口：小红书创作者服务中心 → Builder Hub → 小工具。

## 本地开发

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev:web
```

如需重新生成原创音频，本机需安装 ffmpeg，然后运行：

```bash
npm run generate:audio
```

Web 开发服务器默认监听 `http://127.0.0.1:5173`，根路径 `http://127.0.0.1:5173/` 即街机版游戏入口。

微信小程序直接用微信开发者工具打开仓库根目录；每次修改共享题库或核心逻辑后先执行：

```bash
npm run sync:mini
```

## 验证

```bash
npm run check
```

该命令依次执行两端类型检查、题库/状态机/账本/视觉资产测试、Web 静态构建以及源码/产物隐私扫描。Vite 会一次生成根选择页和四个独立 H5 目录，可直接放入同一个静态服务器目录。
