# 隐私与零数据边界

## 产品行为

答案、当前题目、六类成本账本、五条时间轨道、分数和结局仅保存在 JavaScript 运行内存中。项目没有 HTTP API、数据库、Cookie、客户端持久化、统计 SDK 或错误上报。配乐和音效随 Web / 小程序代码本地打包，不从第三方服务器加载；声音开关也只保存在当前运行内存中。

Web 页面刷新或关闭后状态消失；小程序页面销毁或重新进入后重新创建初始状态。结局不会写入 URL，也不提供结果分享。

## 平台边界

静态服务器、CDN、浏览器和微信平台可能按各自规则记录普通访问日志。这些日志不包含本产品的答案、经营账本或结局，因为产品没有发送这些数据的代码路径。

## 自动检查

`npm run audit:privacy` 会扫描 Web 源码、Web 编译产物和小程序源码，阻断网络、上传下载、客户端持久化、身份、分享和外部资源接口。

小程序允许的唯一分享相关调用是 `wx.hideShareMenu`，用途是隐藏分享入口。
